📁 百益联盟广告SDK - AAR/JAR 放置目录
=========================================

⚠️ 请将以下文件从百益联盟官方SDK包中复制到此目录：

步骤1：从金山文档下载SDK包
   链接：https://www.kdocs.cn/l/cosM80ya0XtW
   下载后解压，把里面的 .aar 和 .jar 文件全部复制到本目录

步骤2：需要包含的文件（示例）：
   ✅ ByAdSdk_*.aar          - 百益联盟广告主SDK
   ✅ msa_mdid_oaid_sdk*.aar - OAID SDK（广告标识）
   ✅ 其他 .jar / .aar 文件   - 百益联盟SDK的依赖库

步骤3：确认文件放置后，用 Android Studio 打开 android-app/ 目录
   然后 Build → Rebuild Project 即可
