# 🍎 水果消消乐 - 积分兑换人民币版

> 一款融合了 **百益联盟广告变现** + **积分兑换人民币（提现待续）** 的水果三消游戏

## 🎮 游戏特色

| 功能 | 说明 |
|------|------|
| 🍎 三消玩法 | 8x8棋盘，3个及以上水果匹配消除 |
| 🔥 连锁消除 | 支持连续消除，倍率递增 |
| 🏆 关卡系统 | 自动升级，目标分数递增 |
| 📅 每日签到 | 连续签到奖励递增 |
| 📺 广告变现 | 百益联盟激励视频/插屏/Banner广告 |
| 💰 积分兑换 | 100积分 = 1元人民币 |
| 🏧 提现系统 | 🚧 **即将上线，敬请期待！** |

## 📂 项目结构

```
src/
├── main.py              # 🏁 主入口 & 菜单导航
├── game_engine.py       # 🎯 消消乐核心引擎
├── reward_system.py     # 💰 积分兑换人民币系统（提现待续）
├── ad_manager.py        # 📢 百益联盟广告SDK
└── ui.py                # 🖥️ Android游戏界面
```

## 💰 经济系统

| 项目 | 比例/规则 |
|------|-----------|
| 游戏得分→积分 | 10分 = 1积分 |
| 积分→人民币 | 100积分 = 1元 |
| 最低提现 | 1元起提（🚧待续） |
| 签到奖励 | 10+(天数-1)×5 积分 |
| 看广告奖励 | 5-20随机积分/次 |

> 💡 **积分照常累计，开放提现后可直接兑换！**
